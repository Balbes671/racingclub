Паттерны — структура проекта

Были применены два основных паттерна

Prototype (Прототип) — позволяет создавать новые трассы на основе готовых базовых шаблонов путем их клонирования и последующей модификации параметров (погода, длина, число кругов), не настраивая объект с нуля.

Factory Method (Фабричный метод) — изолирует процесс создания различных типов автомобилей (спорткар, внедорожник, болид) в специализированных классах-фабриках, избавляя клиентский код от жесткой привязки к конкретным классам.

Запуск

- Скачать проект архивом,
- распокавать в удобном месте,
- открыть консоль(PowerShell или Bash),
- перейти в папку с проектом через команду cd "путь к файлу",
- выполнить команду dotnet run
Выполнить команду запуска:

dotnet run
